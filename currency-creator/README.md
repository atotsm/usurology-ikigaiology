# Currency Creator 2.0

A standalone, browser-based studio for exploring complementary-currency models, designing a community currency, composing a monetary ecosystem, testing simplified scenarios, and drafting a community charter.

## Open the app

Open [`index.html`](./index.html) from this folder. If GitHub Pages is enabled for this repository, the public page will be available at:

`https://atotsm.github.io/usurology-ikigaiology/currency-creator/`

## Scope and limitations

- No backend, account, or external runtime dependency is required.
- Project data can be exported locally as JSON or text.
- Simulation outputs are illustrative, not forecasts or empirical findings.
- The app does not issue currency or provide legal, tax, financial, or accounting advice.
- Case-study names are research starting points; verify current rules, operation, outcomes, and applicable law before relying on them.
